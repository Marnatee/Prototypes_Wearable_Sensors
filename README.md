# Wearable Sensor Research Prototypes

Prototype systems developed in support of undergraduate research on
micro-behavioral patterns, multimodal sensing, and AI at California
State University, San Bernardino.

## Current Prototypes

### Prototype 0.3 — ESP32-CYD + MPU-6050
Initial IMU sensing prototype using an ESP32-based development board
and MPU-6050 accelerometer/gyroscope.

### Prototype 1.2 — Wearable IMU
Wearable inertial sensing prototype for motion-data collection.

### Prototype 2.2 — Directional mmWave
Directional mmWave sensing prototype for contactless behavioral sensing.

### Kinect v2
Development and testing involving Kinect-based motion sensing.
